No ecossistema de tecnologia moderno, ferramentas de código aberto e soluções comunitárias têm substituído softwares comerciais caros com vantagens claras: transparência, velocidade e privacidade.

O **Onlook** é um excelente exemplo dessa transformação.

---

### Principais Recursos e Benefícios

* **01**: 🎨 Edita espaçamento, cor e fonte direto na tela
* **02**: ⚛️ Grava a mudança direto no código React e Tailwind
* **03**: 🤖 Pede ajustes de layout com IA sem perder controle
* **04**: 🔓 Código aberto rodando direto na sua pasta local

---

### Como Começar

Para explorar e testar o projeto no seu ambiente:

```bash
# Acesse o repositório oficial no GitHub
git clone https://github.com/onlook-dev/onlook.git
cd $(basename "onlook-dev/onlook")
```
