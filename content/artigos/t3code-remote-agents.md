No ecossistema de tecnologia moderno, ferramentas de código aberto e soluções comunitárias têm substituído softwares comerciais caros com vantagens claras: transparência, velocidade e privacidade.

O **T3 Code** é um excelente exemplo dessa transformação.

---

### Principais Recursos e Benefícios

* **01**: 📱 Aprova comandos de Claude Code e Codex direto no iPhone ou Android
* **02**: 🔀 Troca de modelo no meio da mesma tarefa entre Claude, Codex e Cursor
* **03**: 🌿 Cria worktree Git isolado por thread para revisar diff e abrir PR
* **04**: 🔒 Roda na sua máquina usando suas próprias assinaturas sem revenda

---

### Como Começar

Para explorar e testar o projeto no seu ambiente:

```bash
# Acesse o repositório oficial no GitHub
git clone https://github.com/pingdotgg/t3code.git
cd $(basename "pingdotgg/t3code")
```
