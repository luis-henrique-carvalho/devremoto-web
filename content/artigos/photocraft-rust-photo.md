No ecossistema de tecnologia moderno, ferramentas de código aberto e soluções comunitárias têm substituído softwares comerciais caros com vantagens claras: transparência, velocidade e privacidade.

O **PhotoCraft** é um excelente exemplo dessa transformação.

---

### Principais Recursos e Benefícios

* **01**: 🗂️ Abre e edita arquivos PSD com camadas e máscaras
* **02**: 🎚️ Camadas de ajuste, curvas, pincéis e tipografia
* **03**: 🦀 Escrito do zero em Rust para rodar leve sem travar
* **04**: 💻 Funciona offline no Windows, Mac, Linux e navegador

---

### Como Começar

Para explorar e testar o projeto no seu ambiente:

```bash
# Acesse o repositório oficial no GitHub
git clone https://github.com/storytold/photocraft.git
cd $(basename "storytold/photocraft")
```
