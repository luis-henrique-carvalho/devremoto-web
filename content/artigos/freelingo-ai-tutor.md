No ecossistema de tecnologia moderno, ferramentas de código aberto e soluções comunitárias têm substituído softwares comerciais caros com vantagens claras: transparência, velocidade e privacidade.

O **FreeLingo** é um excelente exemplo dessa transformação.

---

### Principais Recursos e Benefícios

* **01**: 🎙️ Conversa por voz em 50 cenários reais do dia a dia
* **02**: 🗺️ Plano semanal estruturado do nível A1 ao C2 (CEFR)
* **03**: 🧠 Flashcards SM-2 e 3 jogos práticos de fixação
* **04**: 🐳 Roda no seu servidor com Docker, Ollama ou OpenAI

---

### Como Começar

Para explorar e testar o projeto no seu ambiente:

```bash
# Acesse o repositório oficial no GitHub
git clone https://github.com/artcc/freelingo.git
cd $(basename "artcc/freelingo")
```
