No ecossistema de tecnologia moderno, ferramentas de código aberto e soluções comunitárias têm substituído softwares comerciais caros com vantagens claras: transparência, velocidade e privacidade.

O **Yazi** é um excelente exemplo dessa transformação.

---

### Principais Recursos e Benefícios

* **01**: ⚡ Abre pastas com milhares de arquivos sem travar
* **02**: 🖼️ Mostra preview de foto, PDF e código na hora
* **03**: ⌨️ Navegação estilo Vim com busca instantânea
* **04**: 🦀 100% escrito em Rust com plugins em Lua

---

### Como Começar

Para explorar e testar o projeto no seu ambiente:

```bash
# Acesse o repositório oficial no GitHub
git clone https://github.com/sxyazi/yazi.git
cd $(basename "sxyazi/yazi")
```
