No ecossistema de tecnologia moderno, ferramentas de código aberto e soluções comunitárias têm substituído softwares comerciais caros com vantagens claras: transparência, velocidade e privacidade.

O **Magpie** é um excelente exemplo dessa transformação.

---

### Principais Recursos e Benefícios

* **01**: 🔀 Troca o modelo de Claude Code, Codex e Gemini numa lista só
* **02**: 🔄 Muda para sua próxima conta quando a cota diária acaba
* **03**: 🛡️ Mascara chaves, senhas e e-mails antes do prompt sair do PC
* **04**: 💻 Gateway local compatível com Mac, Windows, Linux e Docker

---

### Como Começar

Para explorar e testar o projeto no seu ambiente:

```bash
# Acesse o repositório oficial no GitHub
git clone https://github.com/yetone/magpie.git
cd $(basename "yetone/magpie")
```
